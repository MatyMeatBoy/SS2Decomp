## Lessons

New agbcc mechanisms from this push are in
[HARD_FUNCTIONS.md](HARD_FUNCTIONS.md#agbcc-mechanisms-confirmed-2026-11-07).
For the two giant functions, useful hypotheses included merging m2c register
families and removing pointer temporaries that represent GCSE/PRE expressions.
Continue with bounded experiments on real value lifetimes: first reproduce an
unchanged full-module control, audit every affected use, and compare complete
bytes and relocations. Size or heuristic improvements alone do not prove a
correct candidate or recover the original source-variable identities.
