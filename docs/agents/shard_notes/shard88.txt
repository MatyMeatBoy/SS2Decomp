2026-11-07 (claude-nov07-w85): sub_080855D4
  Filtered nmdiff 823 -> 702 (aligned 440 -> 368, register-blind aligned 166 -> 149); size 4616

  - Table gUnk_084ECC2C is read as u16 halfwords: cat = tab[i * 2 + 1], id = tab[i * 2]. The ROM
    computes (i << 2) + 2 before adding the base, and every "find cat" loop's induction pointer starts
    at base + 2 (`adds r1, #2`), then `ldrh [r1, #0]`. With the struct form the +2 stayed in the
    addressing mode. That made the duplicated entry test of the `count` loop identical to the bottom
    test, so cross-jumping turned it back into "b test", and the constant pool was dumped at that
    barrier (+44 bytes there).
  - Random-point loop: `j = rand() & 0xFF` into the function-scope j (not a block-local u8): the AND
    stays an `ands` with a rematerialised 0xFF and r/zero land in r5/r6 as in ROM.
  - memcpy destination is L.win.item (ROM `add r0, sp, #0x2d4`), not win->item.
  Remaining: n is in r9 and item in sl (ROM: item r9, n sl). In global-alloc a gcse pointer
  (item + 0xD4, 4 refs / 36 insns) takes r9 before item and conflicts with it; in ROM that pointer is
  spilled. pts/pos/speed addresses: ROM forms sp + off before the scaled index (we compute i << 3
  first); a 2-D `s32 pts[25][2]` and `(&L.pts[0])[i]` did not change it.
  Follow-up (same day): filtered 702 -> 676, register-blind aligned 149 -> 132, size 4604.
  - The table is u16 rows `gTab855D4[][2]` ([x][1] = cat, [x][0] = id). With a flat u16 array,
    (x * 2 + 1) * 2 is not folded when x is a sum (lsl/add/lsl); the 2-D form gives the ROM
    `lsls #2; adds #2; adds base`. Byte-offset forms fold the +2 into the symbol (worse).
  - item->unk22 dispatch is `if (unk22 != 0) { switch { case 1: ...; break; case 2: ...; break; }
    draw }`. A two-case switch gives the ROM's linear cmp 0/1/2 chain; the old 0/1/2 switch was a
    balanced tree.

    `adds #4`), and ROM forms sp+off before the scaled index everywhere (pts/pos/speed). This suggests
    the arrays aren't members of one frame struct at the same nesting, or their address is a variable.
    `(cursor + 1) + index` keeps ROM's order only in some variants. Frame slots 0x5E8.. are shifted by
    one (L.use pointer / count / last).
