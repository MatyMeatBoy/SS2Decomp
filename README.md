# Shining Soul II (Europe) — Decompilation

Work-in-progress decompilation of **Shining Soul II** for the Game Boy Advance
(Europe, `AU2P`, multi-language En/Fr/De/Es/It).

This repository does **not** contain the ROM. You need your own dump:
