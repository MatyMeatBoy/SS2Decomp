# Formats of data objects that stay as raw bytes in data/*.s but whose format is known.
# label-regex  type  evidence
# Types: palette = BGR555 colours, 512 or 1024 bytes; tiles4 = 4bpp 8x8 tiles, 32 bytes each;
# text = bytes in the game character set, 0xFF line break, ends with its only 0xFD.
# data_progress.py applies the size rule of the type from source alone; data_extract.py decodes
# the objects from the ROM (check, png). A label that fails its size rule is not counted.
#
# Resource archives (ResolveResourceByEncodedId): categories 1, 3 and 6 hold a graphic and, in the
# second slot ("b"), its palette; category 4 is one tile sheet.
^gRes(Main|Aux)_Cat[136]_\d+b$  palette  second slot of a paired category; every size is 512 or 1024
^gRes(Main|Aux)_Cat[136]_\d+$   tiles4   first slot of a paired category; every size is a multiple of 32; nibble rows repeat with period 4
^gResMain_Cat4_\d+$             tiles4   single 32768-byte sheet
#
# Strings of the five language tables (ResolveResourceByEncodedId kind 20, table chosen by gUnk_03003470).
^gTextL\d_\d+$                 text     every string ends with its only 0xFD; letters decode to readable text
#
# Category 5: sprite frame and animation records, struct Root4SpriteRecord / Root4SpriteFrame / Root4SpriteAnim in
# src/code_08006D24.c (drawn by sub_080072A0). Same ids as the sprite graphics of category 6.
^gRes(Main|Aux)_Cat5_\d+$     sprite_anim  header {u16 frames, u16 anims, s32 frame offset = 12, s32 anim offset}; both tables fit in every resource
#
# Category 2: area maps, read by LoadWorldMapArea (sub_08009930). 16-byte record header, then the map either
# LZ77-compressed or raw (key bit 0x40000000). Map: s16 width, s16 height in a 16-byte header, width*height
# 6-byte cells, then width*height 16-bit entries of the second plane.
^gResMain_Cat2_\d+$          map      all 226 walk exactly: 205 compressed, 21 raw; decoded size = 16 + w*h*8
#
# Category 0: screen tilemaps, read by LoadBackgroundAsset (sub_0800B650). u32 header = id and flags of the
# graphic to load with it, then the tilemap LZ77-compressed, or raw when the caller sets key bit 0x40000000.
^gRes(Main|Aux)_Cat0_\d+$     tilemap  69 of 89 are an exact LZ77 stream after the header; the other 20 are the raw form
#
# Bytes between the end of the aux archive and the end of the ROM. No code, pointer table or archive entry
# refers to them (the only pointer-like words that hit the range lie inside sound samples). Kept verbatim.
^gUnk_08FD5298$                 unused   unreferenced; nothing reads it
